About this dashboard

Built to support the decision, not make it

This tool applies a supervised learning model to the diagnostic features clinicians already collect. It exists to surface a fast, consistent second read — never to replace biopsy, imaging, or a clinician's judgment.

Every prediction is paired with the reasoning behind it, so it can be reviewed, questioned, and confirmed like any other clinical input.
